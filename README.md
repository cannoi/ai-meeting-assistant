# AI Meeting Assistant (Trợ lý cuộc họp AI)

A bilingual English and Vietnamese meeting assistant that records meetings in the browser or imports audio files, produces an editable timestamped transcript, generates concise meeting summaries, identifies decisions and action items, and exports clean notes and task lists.

## Features
- Browser microphone recording and audio file upload
- Bilingual English & Vietnamese support
- Secure AI consent workflow
- Manual transcript fallback and editable timestamped segments
- AI meeting analysis, decisions, and action items tracking
- Export to Markdown, Plain Text, and CSV with UTF-8 support
- SQLite local persistence
